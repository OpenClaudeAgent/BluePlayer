ERROR CAPTURED:
  "The \"Client-ID\" header is invalid." (HTTP 400 Bad Request)

ROOT CAUSE CONFIRMED:
  Qt normalizes HTTP header names to lowercase during transmission
  Twitch GraphQL API rejects lowercase "client-id" header
  Helix API accepts lowercase headers (works fine)
