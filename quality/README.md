# Quality - Agent Quality

Ce dossier contient les rapports de qualite produits par l'agent Quality.

## Structure

```
quality/
  README.md              # Ce fichier
  STATUS.md              # Suivi des rapports
  HISTORY.md             # Historique des analyses
  review-XX-*.md         # Code reviews
  validation-XX-*.md     # Validations de tests
  report-XX-*.md         # Rapports de test manuels
```

## Methodologie

1. **Code Review** : Analyse du code source avec la checklist du skill `code-review`
2. **Tests Review** : Validation des changements de tests fonctionnels
3. **Tests Manuels** : Plans de test et accompagnement utilisateur

## Regles

- L'agent Quality **ne modifie jamais** le code source
- Tous les rapports sont dates et numerotes
- L'historique permet de suivre l'evolution de la qualite
